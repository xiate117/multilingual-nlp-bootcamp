# multilingual-nlp-bootcamp

第 1 周多语言 Word2Vec 实验。所有文件保存在本地，不上传到 GitHub。

运行：

```powershell
cd week01_embeddings
python week01_embeddings.py
```

详细说明见 [week01\_embeddings/README.md](week01_embeddings/README.md)。

```text
multilingual-nlp-bootcamp/
├─ README.md
└─ week01_embeddings/
   ├─ data/                  # 现成的五种语言 UTF-8 文本
   ├─ outputs/               # 词频、模型和近邻查询结果
   ├─ report/
   ├─ week01_embeddings.py
   ├─ requirements.txt
   └─ README.md
```
